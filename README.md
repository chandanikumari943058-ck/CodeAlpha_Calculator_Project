# 🧮 Calculator Web App

A simple and modern Calculator Web App built using **HTML, CSS, and JavaScript**. This calculator helps users perform basic mathematical calculations with an attractive and user-friendly interface.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📊 Percentage calculation
- 🧹 Clear (AC) button
- ⌫ Delete button
- 🎨 Attractive and modern UI
- 📱 Responsive design
- 🌙 Theme change option
- 🕒 Calculation history

## 🛠️ Technologies Used

- **HTML5** – Structure of the calculator
- **CSS3** – Styling and layout
- **JavaScript** – Calculator functionality

## 📸 Project Preview

Open the `index.html` file in your browser to see the calculator.

## 🚀 How to Run This Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure all project files are in the correct location.
4. Open `index.html` in your browser.
5. Start calculating!
